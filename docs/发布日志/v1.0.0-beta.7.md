# 🎉 版本 v1.0.0-beta.7 更新日志

## QcClip 版本更新

### 新增

- **双栏列表布局**：主窗口新增左右双栏和上下双栏布局，可同时查看剪贴板历史和收藏，可在设置或标题栏菜单中切换。两栏共用搜索和筛选，各自保留滚动位置与选中状态；鼠标移入列表或按左右方向键即可切换当前操作的列表，当前列表以主题色顶部边框标记。拖动分隔条可调整两栏比例，双击分隔条恢复均分，比例会自动保存。
- **文件粘贴选项**：文件类型条目的右键粘贴菜单新增“文件名称”和“文件路径”选项，可直接粘贴为文本；对文件执行纯文本粘贴时，优先粘贴文件路径。
- **标记不存在的文件**：主窗口列表中，已被删除或移动的文件会标记为“文件不存在”，便于识别失效条目。
- **全局粘贴音效**：粘贴音效新增“全局生效”选项，开启后在任意应用中按下粘贴快捷键时都会播放粘贴音效。
- **滚动兼容**：常规设置新增“滚动兼容”选项，解决鼠标悬停在 QcClip 窗口上时，滚轮滚动被 Excel 等其他活动窗口抢占的问题。
- **WebDAV 支持 HTTP**：WebDAV 地址支持使用 HTTP，方便连接局域网或自建服务。
- **记住便签外观与拆词配置**：自动记住最近调整的便签颜色、不透明度、置顶状态和拆词选项，新建便签时沿用这些偏好，已有便签各自恢复原有配置。

---

### 优化

- **虚拟组网设备配对**：配对附近设备时，会向每个网卡所在子网发送发现广播，支持发现和配对 ZeroTier 等虚拟组网中的设备。
- **图文混排显示**：优化列表和预览中图文混排内容的显示效果，限制图片宽度并去除首尾多余空行。
- **关闭材质时的性能消耗**：关闭窗口材质后不再启用背景模糊，减少不必要的性能消耗。
- **热度滚动条样式**：优化热度滚动条在鼠标未悬停时的样式，减轻视觉干扰。
- **“使用默认程序打开”图片缓存**：同一图片条目多次用默认程序打开时复用同一个临时文件，删除条目时一并清理对应缓存。
- **菜单勾选对齐**：菜单统一预留勾选图标的位置，勾选状态变化时菜单项不再错位。

---

### 修复

- **未开启同步时的资源占用**：修复未开启同步功能时，同步后台任务仍持续轮询、占用系统资源的问题。
- **列表 GPU 占用异常**：修复鼠标在主窗口列表上移动时 GPU 占用异常升高的问题。
- **重复复制未更新历史**：修复重复复制相同内容时，历史记录未更新的问题。
- **单击行为漏响应**：修复连续快速单击时，只有第一次点击会触发单击行为的问题，现每次点击都会响应。
