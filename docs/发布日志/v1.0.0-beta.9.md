# 🎉 版本 v1.0.0-beta.9 更新日志

## QcClip 版本更新

### 新增

- **外置标签面板**：标签面板新增独立窗口并设为默认模式，自动选择主窗口附近的位置，随主窗口显示与隐藏，减少对列表空间的占用。点击标签按钮即可展开或收起，也可在主窗口设置中切回窗口内显示。
- **便捷粘贴按住滚动**：便捷粘贴新增“按住触发键滚动”模式并设为默认。点按触发键下移一项，长按连续向下滚动，松开触发键停止滚动，组合键全部松开后粘贴；也可切回“松开触发键立即粘贴”模式。
- **文件与图文混合合并**：文件支持与文字、富文本和图片一起合并复制、粘贴。与文字、富文本混合时，普通文件以路径加入，可解码的图片文件直接嵌入为图片；仅合并文件，或将文件与原生图片组合时，同时保留文件列表和路径文本，方便在不同应用中粘贴。
- **背景图自动配色**：设置自定义背景图后，可选择“背景图色彩”外观模式，根据图片自动搭配界面颜色，让主题与背景更加协调。
- **失效文件项清理**：数据管理新增“清理失效文件项”，可清理所有文件均已无法访问的纯文件历史记录，收藏内容不会被删除。
- **文件与路径快捷打开**：文件条目的右键菜单新增“打开所在目录”，可在系统文件管理器中定位原始文件；纯路径文本也支持通过右键菜单“使用默认程序打开”。
- **列表时间显示**：列表预览设置新增“时间显示”选项，支持绝对时间与相对时间，默认显示本地日期和时间，也可切换为“几分钟前”等相对时间。
- **剪贴板排除标记过滤开关**：剪贴板格式设置新增“尊重剪贴板排除标记”选项，默认跳过被来源应用标记为禁止监控或禁止加入历史的内容；关闭后可读取这类内容。

---

### 优化

- **开机自启动**：统一使用 Windows 计划任务管理开机自启动，管理员模式下开机启动不再弹出 UAC 确认窗口。
- **列表多选交互**：多选时点击条目用于切换选择，鼠标悬停不再改变选中项，并隐藏单条操作按钮；粘贴与删除快捷键作用于所选条目，减少误操作。
- **图片格式识别与预览**：补齐 WebP、JPEG、GIF、BMP、TIFF、ICO 等常见剪贴板图片格式的识别，统一图片预览的选择顺序，优先使用 PNG、WebP 等格式。
- **Emoji 显示**：表情面板改用 Twemoji 图片，统一不同 Windows 版本下的显示效果，减少因系统字体差异导致的表情缺失或样式不一致。
- **悬停气泡提示**：新增独立气泡提示窗口，统一各处悬停提示的样式与显示行为。
- **应用图标尺寸**：调整应用图标的显示比例，改善图标比其他应用偏小的问题。

### 修复

- **旧版系统窗口渲染**：修复旧版 Windows 系统下窗口画面渲染异常的问题。
- **文件粘贴格式与优先顺序**：修复文件粘贴时格式保留不完整、优先顺序不正确的问题。默认粘贴优先提供文件列表；纯文本粘贴或关闭格式粘贴时，优先提供路径文本并保留文件列表，兼顾文本输入与文件粘贴场景。
- **跨设备同步重复记录**：修复跨设备同步时，相同内容被重复记录的问题。
- **中文输入候选词选择**：修复搜索框中文组字时，窗口内临时快捷键抢占方向键，导致无法正常选择输入法候选词的问题。
- **系统文本预览乱码**：修复部分 Windows 原生文本格式预览时出现乱码的问题，按对应系统编码读取文本。
- **主窗口任务栏图标**：修复部分设备上主窗口意外出现在任务栏中的问题。
- **拖拽预览跟随卡顿**：修复拖拽预览因绘制调度延迟，跟随鼠标移动时出现卡顿的问题。
- **快捷键下拉框文字截断**：修复快捷键组合下拉框中文字显示不完整的问题。
