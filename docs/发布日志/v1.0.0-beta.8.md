# 🎉 版本 v1.0.0-beta.8 更新日志

## QcClip 版本更新

### 新增

- **多选条目批量管理标签**：多选条目后，可通过多选操作栏或右键菜单批量添加、移除标签。
- **多选右键菜单**：多选条目后右键可直接合并复制、合并粘贴、管理标签、批量删除或取消选择；在收藏页中可批量取消收藏。
- **模拟粘贴方式**：常规设置新增“模拟粘贴方式”，支持“自动”“Ctrl+V”和“Shift+Insert”。自动模式会避开被 QcClip 快捷键占用的粘贴组合键，并为 PuTTY、Git Bash 等终端选择 Shift+Insert，也可手动指定以适配不同应用。
- **类型筛选模式**：主窗口设置新增类型筛选的单选与多选模式，可选择每次仅筛选一种类型，或同时筛选多种类型。
- **颜色代码预览**：自动识别剪贴板中的颜色代码，在列表中显示对应色块并保留原始文本，支持十六进制、RGB、HSL 等常见格式，便于直观查看颜色。
- **首次使用引导**：新增首次使用引导页，帮助选择外观、设置呼出快捷键、调整点击粘贴与开机启动等使用习惯。
- **文本编辑字号调整**：文本编辑窗口支持通过 **`Ctrl + 滚轮`** 或 **`Ctrl + 加号 / 减号`** 调整字号，并自动记住缩放比例，方便阅读和编辑。

---

### 优化

- **自动更新与下载线路**：自动检查更新失败后保留重试间隔，避免重启时反复检查；下载时对 GitHub 和 Gitee 线路测速，优先使用较快的可用线路，遇到失败、停滞或持续低速时自动切换备用线路。
- **外观与主题选择**：外观模式改为可视化预览卡片，主题配色改为色板选项，选择浅色、深色或跟随系统模式及对应主题时更加直观。
- **主窗口显示与隐藏动画**：主窗口显示和隐藏改用弹簧曲线，展开与收起更加自然。
- **Windows 10 窗口材质**：Windows 10 不再提供亚克力材质，已有亚克力设置自动改用模糊效果。
- **列表状态与多选框**：优化列表项的状态边框线和多选框显示效果。
- **条目信息与操作显示**：条目信息、工具栏和操作按钮的“悬停或选中”选项调整为仅在鼠标悬停时显示，减少选中条目时的视觉干扰。

---

### 修复

- **局域网同步连接**：修复设备系统时间存在偏差时，局域网同步可能一直显示未连接的问题；补充同步诊断日志、连接失败原因和必要通知，便于排查。
- **WebDAV 数据包下载**：修复部分 WebDAV 服务返回的文件大小与实际下载大小不一致时，备份数据包被误判为大小变化、导致下载失败的问题。
- **中键呼出失效**：修复 Ctrl、Alt、Shift 等修饰键状态残留，导致鼠标中键无法呼出主窗口的问题。
- **远程工具鼠标兼容**：修复使用远程控制工具时，部分鼠标功能无法正常响应的问题。
- **重复复制提示**：修复连续复制相同内容时，反复弹出通知和播放音效的问题。
- **启动时任务栏图标**：修复应用启动时主窗口意外出现在任务栏中的问题。
- **主窗口动画被任务栏遮挡**：主窗口在显示动画开始前即置顶，修复动画末段被任务栏遮挡的问题。
- **久未呼出时动画跳过**：修复主窗口长时间未呼出后，再次显示时动画被跳过的问题。
- **关闭材质后组件半透明**：修复关闭窗口材质后，部分组件仍保持半透明的问题。
- **首行信息占位**：修复首行信息设为悬停显示时仍始终占用空间的问题，现仅在鼠标悬停时展开，收起后释放空间。
- **便签提示文字**：修复便签窗口内提示文字对比度不足、难以辨认的问题。
- **侧边标题栏按钮排列**：修复标题栏位于侧边时，“上传 / 拉取”按钮仍横向排列的问题，现随标题栏纵向排列。
